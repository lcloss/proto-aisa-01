Sistema de Design

Os tokens reais da marca AISA — cor, tipografia, espaço e componentes — renderizados a partir de tokens/base.css. Sistema 100% personalizado, sem bibliotecas de UI externas. O que vês aqui é exactamente o que o tema WordPress que consuma o base recebe.

Sobre este sistema

Deriva da identidade visual (04-brand-visual-identity.html) e do brief de requisitos (03-brand-requirements.md). Cada token traça-se de volta à paleta, tipografia ou princípios da marca.

Modo claro apenas. Por decisão de requisitos (público sénior, que valoriza previsibilidade e legibilidade acima de tudo), este sistema não tem modo escuro — logo, não há alternador claro/escuro. Todos os pares de texto sobre superfície cumprem WCAG AA, validado por scripts/check-contrast.mjs e re-calculado ao vivo nesta página.
Design system próprio, alvo WordPress. Por decisão de requisitos (2026-07-04), este sistema é 100% personalizado — sem Tailwind CSS, sem shadcn/ui, sem qualquer framework de UI. Todos os componentes são HTML + CSS nativo construídos a partir dos tokens, prontos a consumir num tema WordPress (ver tokens/wordpress.md).

Cores

Tokens OKLCH, semânticos por papel. O rácio de contraste ao lado de cada amostra é calculado neste browser a partir da cor efectivamente aplicada — deve bater certo com o gate de geração.

Como consumir

O base é a fonte da verdade: CSS nativo, sem build e sem bibliotecas externas. O alvo de implementação é um tema WordPress próprio.

1. CSS puro (qualquer página)

<link rel="stylesheet" href="tokens/base.css">

.botao {
  background: var(--color-primary);
  color: var(--color-primary-foreground);
  border-radius: var(--radius-md);
  box-shadow: var(--shadow-sm);
}

2. Tema WordPress

// functions.php — os tokens entram antes da folha do tema
add_action( 'wp_enqueue_scripts', function () {
  wp_enqueue_style( 'aisa-tokens', get_theme_file_uri( 'assets/css/base.css' ), array(), '1.0' );
  wp_enqueue_style( 'aisa-theme', get_stylesheet_uri(), array( 'aisa-tokens' ), '1.0' );
} );

Vê tokens/wordpress.md — enfileiramento dos tokens, paleta do editor via theme.json (por referência às variáveis, sem duplicar valores), estilos do editor e integração dos formulários. Os componentes desta página copiam-se para a folha de componentes do tema tal como estão — sem Tailwind, sem shadcn/ui, sem frameworks de UI.

Validação. Antes de entregar, corre o gate de contraste:
node scripts/check-contrast.mjs --tokens tokens/base.css
node scripts/check-contrast.mjs pairs.json
